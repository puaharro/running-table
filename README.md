# NXTGO｜香港路跑資訊

正式開發 v0.2.0，2026-10-21。以一頁總覽搵賽事，連到獨立資訊頁及原創指南；開發方式參照 MTRI 嘅 Next.js、React、TypeScript 及 Git 管理。

## 2026-10-25 資料覆核

已重新核對現有 6 場官方資料：補齊渣馬半馬／10K 本地費用、起點及時限；UNICEF 金額按最低籌款額顯示，公開個人報名選單可選 10K 一組、5K、3K，半馬狀態仍待確認。完整來源與限制見 SOURCE_LEDGER。會員及額外渠道仍未加入。

## 多渠道報名更新

每個組別的 channels 為獨立報名紀錄，現有 6 場、14 組、21 個渠道。新增一般／優先／慈善／住宿連名額篩選，類型及狀態須在同一渠道符合；詳情分開列出資格、價格、申請／結果／付款日期及來源。未知慈善名額及套票餘額保持待核實。

## 本批完成

- 正式頁面改用 6 場真實活動、14 個組別，逐項記錄官方來源、核實時間及修改紀錄。
- 舊 12 場虛構資料移入 tests/fixtures，只用作測試，唔會匯出成頁面。
- 日期、距離、地區、運動類別、報名狀態組合篩選；關鍵字搜尋、截止日期排序、分享與返回保留條件。
- 報名渠道清楚列明；按香港精確時間判斷截止，超過 72 小時未核對嘅狀態顯示待核實。
- 組別起點可分開篩選；費用、資格及起點未核實時留空，唔用其他組別資料代填。
- 三篇原創指南；賽事頁提供官方資料連結、核實依據及修改紀錄。
- 發布資料驗證、待核實清單、SEO／sitemap／結構化資料設定、搜尋收錄設定檢查、GitHub Actions。
- 32 項測試、TypeScript、生產建置及匯出連結檢查。

第一階段只做路跑；會員、收藏、加入日曆仍留待第二階段。

## 本地使用

```text
npm ci
npm run dev
```

建置後預覽：

```text
npm test
npm run build
npm run check:export
npm start
```

預覽網址由啟動程序顯示，預設 http://127.0.0.1:3000。`npm run review:data` 列出需要補資料、重新核對或即將截止嘅組別；`npm run format` 統一程式排版。

## 發布狀態

目前係真實資料測試版，預設 noindex；未接入 AdSense、未公開部署，repo 已連接 GitHub。唔聲稱已覆蓋香港全部賽事，亦唔保證即時餘額。

公開收錄需要設定正式 HTTPS 網域、真實營運者及聯絡電郵，再明確設定 SITE_INDEXABLE=true。網站會檢查必要設定；詳細清單見開發文件。品牌按使用者決定改為「NXTGO」，公開聯絡資料稍後補齊。

本地 Git 保留開發分支與提交。GitHub Actions 會於 main 更新或 Pull Request 執行；每次修改以對應工作流程結果為準。

側欄及內容廣告安排見 [廣告版位規劃](docs/ADVERTISING.md)。
