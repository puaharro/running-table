# NXTGO｜香港路跑資訊

私人多來源評論研究：`npm run research:comments`，開啟本機工作區搜尋／保存 Marathon’s World、Facebook、Threads、Instagram、YouTube、網誌及運動筆記材料，再接人工覆核與摘要。[操作說明](docs/COMMENT_RESEARCH.md)。搜尋入口不會自動抓取，沒有公開發布或新增分數。

正式開發 v0.2.0，2026-10-21。以主頁發掘精選賽事，另設搜尋／時間表搵賽事，連到獨立資訊頁及原創指南；開發方式參照 MTRI 嘅 Next.js、React、TypeScript 及 Git 管理。

## 文件入口

Threads Collector V0.1 已加入私人 CLI：先收集公開搜尋命中及 API 可讀取的 conversation，保存原始資料、分頁進度及來源，之後另做評分。設定 token、收集大阪馬拉松、續跑及資料表說明見 [Threads Collector 使用文件](docs/THREADS_COLLECTOR.md)。

```text
npm run collect:threads -- --race "Hong Kong Marathon" --year 2027 --keywords-file docs/examples/threads-hong-kong-marathon.json
npm run test:threads
```

未有 Threads token 亦可先試私人資料檢視頁：`npm run inspect:threads -- --demo --serve`。頁面清楚標示虛構示範資料，支援搜尋、父子回覆及錯誤進度；真正收集後可用同一工具檢視或匯出私人 HTML／JSON。

香港賽事清理、去重及相關性篩選：`npm run clean:threads -- --demo --preset hk-marathon --serve`。規則會分為保留／待覆核／排除，保存原文及逐項原因，暫時不做評分；真正收集後改用 `--run RUN_ID`，詳見上述使用文件。

逐條人工覆核：`npm run review:threads -- --demo`。可確認保留／排除、修正賽事名稱及年份、儲存備註，並保留修改歷史；真正資料用 `--input` 指定清理 JSON。覆核保存於獨立私人 SQLite，重新開啟仍保留，不會修改原文或產生評分。

未有 token 可直接執行 `npm run import:threads`，在本機頁面貼香港賽事 Threads 原文及來源連結，再一鍵接清理、去重與人工覆核。支援只有主帖來源的留言，保留原文版本及歷來快照；手動資料會標示未經 API 驗證，與示範及 API 收集資料分開保存。

覆核後可開「已確認留言資料集」，按你修正的賽事及年份分組，下載私人 JSON／CSV。只收錄已保存的人工保留決定；缺資料或同來源衝突留待再處理，所有原文與覆核版本仍可追溯，沒有評分。

已確認留言亦支援交通、寄存、水站、賽道及賽事組織的多選主題分類。自動建議附原文命中依據，可人工增刪、選「其他」或標記未確定；主題修正及歷史會保存，亦可按主題篩選和匯出，原文、來源、賽事與年份修正保留，暫時不做評分。

由「已確認留言資料集」可進入「賽事／年份／主題摘要」。每個重點由原文摘錄，附完整原文、來源及覆核依據；可人工修正、標記未確定、排除或還原，保留版本歷史並下載 JSON／CSV。摘要、主題及留言的人工確認分開標示，沒有評分或自動推算共識。

摘要頁亦可進入「比較同一賽事唔同年份」，明確選擇左右快照、同一賽事與兩個年份，並排對照各主題重點。原文、來源、人工修正及覆核狀態保留；缺資料、已排除或未經摘要確認會分開標示，可下載本次選擇的 JSON／CSV，不判斷改善／退步或產生分數。

跨年份比較每個主題可另存「留言差異」及「待核實事項」人工備註，保留修改歷史及當時原文依據。備註綁定目前快照、年份、主題及摘要篩選；依據改變會提醒重新核對，仍不做評分。

已保存的比較備註可建立多項獨立核實追蹤，記錄待處理／核實中／人工記錄已核實／無法確認、結果、補充來源及日期。每次修改保留歷史與當時原文；上游備註或依據改變會列為需重新核對，不自動把留言當成已證實事實。

## 頁面分工

- `/`：精選賽事、重要報名資訊及原創指南。
- `/races/`：直接顯示搜尋欄、篩選及賽事時間表，不設主視覺橫幅。
- 舊主頁篩選連結會自動轉到搜尋頁，並保留條件及賽事位置。

## 本地使用

```text
npm ci
npm run dev
```

建置後預覽：

```text
npm test
npm run build
npm run check:export
npm start
```

預覽網址由啟動程序顯示，預設 http://127.0.0.1:3000。`npm run review:data` 列出需要補資料、重新核對或即將截止嘅組別；`npm run format` 統一程式排版。

## 發布狀態

目前係真實資料測試版，預設 noindex；未接入 AdSense、未公開部署，repo 已連接 GitHub。唔聲稱已覆蓋香港全部賽事，亦唔保證即時餘額。

公開收錄需要設定正式 HTTPS 網域、真實營運者及聯絡電郵，再明確設定 SITE_INDEXABLE=true。網站會檢查必要設定；詳細清單見開發文件。品牌按使用者決定改為「NXTGO」，公開聯絡資料稍後補齊。

本地 Git 保留開發分支與提交。GitHub Actions 會於 main 更新或 Pull Request 執行；每次修改以對應工作流程結果為準。

側欄及內容廣告安排見 [廣告版位規劃](docs/ADVERTISING.md)。
