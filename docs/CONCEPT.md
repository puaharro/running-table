# 香港路跑賽事資訊：產品構想

修訂日期：2026-10-21（香港時間）。本文件保留產品規劃；當前實作以 DEVELOPMENT.md 及 CHANGELOG.md 為準。

本版本取代上一版涵蓋越野、首階段收藏與日曆匯出嘅構想。

## 1. 已確認方向

第一階段只做香港路跑資訊，以公開內容吸引自然搜尋流量，再申請及接入 Google AdSense。收藏、加入日曆同會員系統一併留到第二階段。

範圍包括 5K、10K、半馬、全馬，以及屬路跑性質嘅親子跑、慈善跑。更短或非標準距離按官方組別記錄。越野、行山、鐵人、水上活動等唔納入首階段。

核心承諾：幫香港跑手搵到可靠、更新清楚、容易比較嘅路跑賽事資訊。

商業目標：有用內容 → 搜尋曝光 → 有效閱讀 → 廣告收入。會員功能留待內容與使用量穩定後建立。

## 2. 開發方式參照 MTRI

已讀本機 MTRI-v0 嘅 README、package.json、src 目錄、資料類型、頁面 layout 同 next.config.ts。

已確認現有做法：Next.js App Router、React、TypeScript；人工整理靜態賽事資料；分開 app、components、data、lib；Vitest 邏輯測試；build、lint、test 指令；README 先定義 V0 目標、範圍同 first usable slice。

MTRI README 尚未選定部署平台，本機未見 .github workflow，唔視為已具備 CI 或自動部署。

本項目採用同類技術與迭代方式，建立獨立 repo，唔修改 MTRI。唔複製跑旅問卷、推薦評分或未經核實嘅示範資料。原先 Astro 候選方向改為優先採用 Next.js，方便兩個項目使用相近開發方式。

內容採用靜態生成或伺服器輸出完整 HTML，標題、正文、賽事資料及連結可直接讀取；搜尋與篩選等互動部分由瀏覽器處理。

MTRI 現有安全設定限制 script、connect、image 等外部來源，直接沿用會擋住 Google 廣告。正式接入時按實際整合需要調整來源規則，測試廣告與頁面正常運作。呢點係根據設定推論，未進行廣告載入測試。

## 3. 第一階段頁面

| 頁面               | 用途與內容                                                                 |
| ------------------ | -------------------------------------------------------------------------- |
| 首頁／一頁賽事總覽 | 全站已發布賽事集中同一頁，以五項條件組合篩選；名稱連去獨立資訊頁           |
| 賽事詳情頁         | 每場每屆有獨立頁面，列日期、組別、費用、報名期限、交通、官方連結、更新紀錄 |
| 原創報名及選賽指南 | 指南列表與獨立文章，例如點揀第一場 10K、半馬報名須知、賽事比較方法         |
| 關於／編輯政策     | 網站定位、資料來源、核實方式、作者或編輯身份                               |
| 聯絡／更正         | 可用聯絡方式及更正流程；公開前補上真實資料                                 |
| 私隱與使用條款     | 按實際廣告、分析及網站功能交代營運與資料處理                               |

每場賽事使用帶年份嘅獨立網址，例如 `/races/2027/example-race/`。列表名稱連到呢個站內頁面；官方報名連結獨立標示。指南列表用 `/guides/`，文章用 `/guides/example-guide/`。呢啲只係網址示例，未有實際頁面。

月份／距離專頁按內容需要後續加入，屬額外搜尋入口；使用者可以喺總覽完成搵賽事，毋須先進入月份或距離分類頁。月曆格狀檢視留作後續優化。

### 一頁總覽與組合篩選

全站已發布賽事集中同一頁，按日期及月份分組。預設展示即將舉行賽事，同頁可切換歷屆／全部，唔需要另開年份網站。每個條目代表一場活動嘅一屆，多個組別收喺同一條目，避免重複列出。

| 篩選     | 操作與選項                                                 |
| -------- | ---------------------------------------------------------- |
| 日期     | 今個週末、今個月、下個月、自訂開始及結束日期；指比賽日期   |
| 距離     | 5K、10K、半馬、全馬、其他距離；支援多選及自訂距離範圍      |
| 地區     | 港島、九龍、新界、離島；可再選細分地區；按實際比賽起點分類 |
| 運動類別 | 保留類別欄位，第一階段固定顯示路跑；未收錄類別唔提供可選項 |
| 報名狀態 | 全部、未開放、開放中、候補、已截止、額滿、待核實；支援多選 |

不同篩選條件一齊生效（AND）；同一欄多選係符合其中一項（OR）。日期、距離同報名狀態須由同一個組別同時符合，避免以開放報名嘅全馬配對已截止嘅 10K。跨日組別按日期區間重疊判定。

已完成賽事唔顯示「開放中」；延期取消獨立標示。顯示符合條件組別及條件摘要，保留完整詳情入口。報名資料未知或過舊時顯示待核實。

支援名稱／主辦方／地點關鍵字搜尋、結果數量、已選條件標籤、單獨移除條件、一鍵清除、無結果提示。篩選寫入網址，分享、重新整理及由詳情頁返回都保留條件。

桌面用易比較嘅列表，手機用緊湊卡片及可展開篩選面板。初期同頁顯示全部符合條件結果，資料量增加後可同頁分批載入，保留條件與滾動位置。

列表欄位：日期／星期、可按名稱、地區／起點、距離／組別、運動類別、報名狀態。唔要求註冊就可以睇總覽、使用篩選、閱讀詳情同指南。

第一階段唔顯示登入、收藏或加入日曆按鈕，亦唔提供本機收藏或免登入日曆下載。

## 4. 首頁與閱讀體驗

白底、深色文字、一個重點色；手機優先，繁體中文預設。首頁首屏提供定位、搜尋及最近賽事，避免大幅裝飾圖佔據主要閱讀位置。

建議導航：賽事總覽、報名及選賽指南、關於。

首頁次序：搜尋 → 日期／距離／地區／運動類別／報名狀態篩選 → 今個月／即將截止等快捷條件 → 結果數量與已選條件 → 按月份分組賽事列表 → 原創指南 → 編輯政策與聯絡等連結。

賽事詳情先呈現日期、組別與官方報名入口，再提供交通、組別比較、常見問題及來源。未知資料標示未公布／待核實，唔為篇幅而補造內容。

## 5. 搜尋流量與內容策略

三類內容互相連結：

- 時效需求：「香港 2027 路跑時間表」「某月份香港跑步比賽」。
- 報名需求：「某賽事 2027 報名」「截止日期」「路線」「交通」。
- 長期需求：「香港 10K 比賽」「第一次報半馬要睇咩」。

以上係候選題目，未做關鍵字搜尋量或競爭度研究，唔代表已驗證流量。

每場賽事加入人工核實及原創整理，例如組別比較、報名重點、交通摘要、官方公告變動。引用事實記錄來源，唔搬運 Fitz 整份資料、文章、圖片或主辦方完整文案。

原創指南分「報名」同「選賽」兩類。起步題目可以包括：第一次報路跑要準備咩資料、早鳥／抽籤／候補有咩分別、點比較組別費用與安排、點揀第一場 10K、選半馬要睇路線與時限嘅邊啲資料。涉及個別賽事條款時逐場核實，唔一概而論。指南連到相關賽事，賽事詳情亦推薦相關指南。

初期可用 20–30 場已核實路跑賽事、5–8 篇有實際內容嘅原創指南驗證網站。呢個係內部起步建議，唔係 Google AdSense 最低篇數要求或審批保證。

只建立有足夠資料同獨特內容嘅月份／距離專頁，唔大量產生空地區頁、重複篩選組合或只有換標題嘅薄內容。

SEO 包括每頁獨立標題、描述、canonical、標題層級、內部連結、sitemap、robots 設定及分享預覽。可索引內容用乾淨固定網址；一般搜尋／篩選參數頁按策略設 noindex，唔加入 sitemap。

Event 結構化資料只用於符合條件嘅單一賽事頁，內容須同可見資料一致。Google 活動搜尋體驗有地區及語言限制；唔承諾香港繁中頁有特殊展示，亦唔以特殊展示作流量前提。

過期賽事保留年份、已完成狀態同歷史資料，有新一屆就互相連結，避免舊頁繼續顯示開放報名。

## 6. AdSense 變現規劃

Google 官方網站準備指南重視原創、有用內容及清楚導航。先做好完整可公開閱讀網站，再提交申請；能否獲批同收入需要實際營運驗證。

初期建議喺賽事列表自然段落之間，以及賽事詳情主要資料之後，預留少量清楚標示嘅廣告區；桌面長文章可以評估側欄。呢啲係產品設計起點，唔係 Google 指定版位或數量。

廣告唔偽裝成報名連結，與報名、導航、篩選按鈕保持清楚區分，避免誤點。示範、空白、錯誤同未完成頁唔投放正式廣告。版位預留合理尺寸，避免載入時內容跳動。如用 Auto ads，要覆核對導航及閱讀嘅影響。

正式接入需要真實站點、AdSense publisher 設定、按帳戶提示設定驗證與 ads.txt，並按實際投放地區及 Google 政策處理私隱／同意要求。以上係後續事項，目前未代為申請、開通或建立法律文件。

先用 Search Console 觀察收錄、搜尋曝光、點擊與查詢詞，再按需要接入流量分析。廣告啟用後觀察 page RPM 同收入；唔承諾固定點擊率或收入。

## 7. 資料模型與維護

賽事同組別分開，支援一個活動多個距離、時間及費用。

| 層級 | 欄位                                                                                                      |
| ---- | --------------------------------------------------------------------------------------------------------- |
| 賽事 | 固定 ID、年份、slug、中英文名、主辦方、運動類別、開始／結束日期、地點／地區、官方網址、賽事狀態、原創摘要 |
| 組別 | 固定 ID、日期及已知開始時間、組別名、年齡限制、距離、費用／幣別、報名起止、報名狀態、官方報名入口         |
| 內容 | 正文、交通摘要、常見問題、作者／編輯、首次發布時間、實際修改時間                                          |
| 核實 | 欄位或組別對應來源、最後核實時間、備註、草稿／發布狀態                                                    |

報名狀態：未開放、開放中、候補、已截止、額滿、待核實；賽事狀態另外記錄如期、延期、取消、已完成。

部分組別仍接受報名時，摘要顯示「部分組別可報名」。距離與報名篩選由同一組別同時符合。只知道比賽日期，唔推斷報名開放。

香港日期時間用 Asia/Hong_Kong 語意處理，純日期唔隨裝置時區變動。未知資料用空值；免費費用係 0，未知費用唔填 0。

流程：官方／授權來源 → 整理草稿 → 核實 → 審閱修改 → 發布。收到更正或延期消息優先處理。更新頻率按營運人手決定，尚未設定排程。


獨立 repo 管理程式、資料同內容。`main` 對應可發布版本，短期功能分支完成後用 Pull Request 審閱。GitHub 接入後加入必要資料檢查、類型檢查、核心邏輯測試同建置；呢啲係本項目規劃，唔視為 MTRI 已有流程。

公開上線使用 Google 同訪客可直接開啟嘅正式網址，唔要求會員登入。部署平台喺開發前確認，核對 Next.js 支援、成本、網域同 AdSense 所需設定；MTRI 現有文件未指定平台。

第二階段會員資料需要伺服器儲存及登入權限控制，唔寫入 Git 資料檔。現階段保持穩定賽事 ID，方便日後關聯收藏。

## 9. 里程碑與驗收

1. 範圍與規格：只做路跑，確認資訊架構、資料欄位、內容策略；今次更新呢一步。
2. 公開資訊頁原型：一頁賽事總覽、五項組合篩選、可按比賽名稱、一場獨立賽事詳情、指南列表及一篇原創指南；示範資料清楚標示，唔當正式內容索引。
3. 內容與 SEO：已核實資料、原創指南、真實關於／聯絡資料及私隱等支援頁；檢查手機閱讀、來源、連結、metadata、索引設定。
4. 公開上線與量度：確認部署平台、正式網域、GitHub 流程，連接 Search Console，觀察需求。
5. AdSense：完整內容網站上線後申請，按審核結果處理接入、私隱、ads.txt、版位同效能驗證。
6. 第二階段：會員、收藏、加入日曆及相關同步能力。

第一階段驗收：

- 全部賽事屬路跑，無首階段登入、收藏、日曆匯出功能。
- 360px 手機正常閱讀，無水平捲動，主要操作可用鍵盤完成。
- 正文與官方連結喺初始 HTML 可讀，唔依賴登入。
- 已發布賽事有來源、核實時間及年份；未知資料無虛構。
- 五項篩選可組合使用，正確處理同欄多選、多組別、跨日、已截止、延期取消及空結果；第一階段類別只有路跑。
- 每個列表賽事名稱連去正確年份嘅站內詳情頁，官方報名入口另行標示。
- 分享／重新整理／返回總覽保留篩選條件，結果數量同已選條件一致。
- 指南有原創內容，與相關賽事互相連結。
- 公開內容頁有正確標題、描述、canonical；sitemap 只列要索引嘅有效內容。
- 關於、聯絡／更正、私隱等頁有真實可用內容。
- 廣告與導航／報名清楚分開，載入唔造成嚴重跳動。
- 未獲批前唔聲稱已開通 AdSense；未核實流量前唔承諾收入。
