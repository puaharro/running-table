## 產品方向與已確認決定

- 長期目標是亞洲路跑時間表；MVP 仍然只收錄香港真實賽事。
- 首頁負責焦點賽事／資訊、近期三場、精選及閱讀入口；完整 Search Engine 留在時間表。
- 首頁有可手動切換／手機橫掃的焦點 banner，不自動輪播。目前沒有東馬資料或真實贊助商。
- 墨綠操作、暖白頁面、杏色距離標籤；本地 Noto Sans HK／Inter，Barlow Condensed 只用品牌／裝飾數字。沒有新增套件或外部媒體依賴。
- 目前公開目錄有 **6 場、14 組、41 個渠道、2 篇已批准評論、3 篇指南**。這是此提交的資料快照；較早文件的 21 個渠道／32 項測試等數字屬歷史紀錄。

### 搜尋與卡片要保留的細節

- 年份按鈕顯示當年／下一年數字，月份仍為 1–12；placeholder 是「月份」，沒有加回「全部」。
- 選 5K 只影響賽事配對；卡片仍顯示該賽事**全部距離 tags**，例如美津濃 3K / 5K / 10K。
- 賽事卡只保留名稱、地點、距離、起跑日期，並有明確「詳細資料」入口。不要恢復時間／資料左右兩格。
- 原 URL 參數、分享、排序、已選條件移除、詳情返回篩選及賽事 anchor 均保留。
- 國家選項仍保留；未收錄的國家顯示未收錄空狀態，不補虛構賽事。

## 共用與維護入口

- `src/components/site-navigation.tsx`：依路徑顯示選中狀態；手機五項「首頁／時間表／評級／指南／關於」全部可見。
- `src/app/tokens.css`：本輪色票是 `home-*`，其他核心頁亦引用它；不要只因名稱含 home 就視為首頁專用而刪除。
- `src/app/components.css`：共用導航／頁尾的觸控尺寸及窄屏排列。
- `src/lib/use-clock.ts`：由 registration 元件抽出的共用時鐘；保留原初始時間＋hydration 後同步／每 30 秒更新方式，避免首頁引入完整評論元件樹。`live-registration.tsx` 保留 re-export 相容入口。
- `src/app/layout.tsx`：加上 `data-scroll-behavior="smooth"`，與既有全站平滑捲動及 Next 16 行為一致。
- 目前仍沿用 `globals.css` / `refresh.css` / `components.css` 加頁面覆蓋的架構。後續可整理重複樣式，但先確認所有響應式頁面，勿直接刪除舊 selector。

### 焦點 banner 如何改內容

編輯 `src/data/home-focus.ts`；使用既有真實賽事／指南及可用連結。賽事 slide 的 `validUntil` 過期後會移出；指南可保留。將來確有付費內容時，用 `kind: "sponsored"` 並填 `sponsorName`，畫面會明示贊助。**型別預留不是已有贊助商或廣告系統。**

### 評論與資料不可誤改

- 本輪沒有修改 `catalog.json`、`guides.ts`、`editorial-reviews.json`、`editorial-notices.json`、`rating-policy.ts`、評分、評論原文或審批紀錄。
- 評級索引只重用已批准 `quickTake.summary`、三項分數及觀察範圍；詳細短評、材料、確認及更改紀錄仍在比賽內頁。
- 評論年份與承載頁的當屆年份不同，必須清楚標示；不要把往屆分數當當屆表現、全馬套用半馬，或把未評當零分。維持不設總分。
- 報名狀態／72 小時核對有效性邏輯未改。本輪是設計改版，**不是重新核實官方資料**，沒有更新來源核對時間。
- 下一手如改評論、分數或材料，仍須按 AGENTS.md 重新取得指定完整版本的人手確認。不要代填審批紀錄；私人材料維持在 ignored `.editorial-private/`。

## 驗證與重新啟動

環境使用 Next 16.4.3／React 19.3.0，依賴鎖檔沒有改動。GitHub CI 使用 Node 24；本地驗證環境為 Node 22.15.0。

```sh
npm ci
npm run dev
# 或正式靜態預覽
npm test
npm run build
npm run check:export
npm run test:http
npm start
```

`npm start` 使用 `scripts/serve.mjs` 服務 `out/`，不是 `next start`。預設 port 3000，可用 `PORT=3015 npm start`；本輪預覽用了 3015，但全新環境需自行啟動。本地 localhost 連結不能當成遠端網站。正式 build 後如仍看到舊 chunk／頁面，重新載入瀏覽器再檢查。
