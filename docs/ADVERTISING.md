# AdSense 版位規劃

| 位置                 | 安排                                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------- |
| 電腦左右外側         | 視窗至少 1440px 顯示兩邊直幅示意，中央正文保留閱讀空間；1928px 起兩邊各可容納 300 × 600，較窄時用響應式直幅。 |
| 平板／較窄桌面       | 收起左右直幅，保留內容中段版位。                                                                              |
| 手機（767px 或以下） | 底部固定橫幅，可關閉；頁尾預留空間，讓內容能捲動到橫幅之上。                                                  |
| 手機全屏插頁         | 按底部「查看全屏廣告示意」開啟；可按關閉、繼續瀏覽或 Escape 離開。預覽不自動打斷閱讀。                        |
| 內容中段             | 保留原有 inline 位置。                                                                                        |

左右直幅設於正文外側，取代之前列表內的單一右側廣告位；詳情及指南同樣使用這個全站版面。手機參考使用者截圖的全屏插頁及底部橫幅形式，示意圖不使用截圖中的廣告素材。

## 預覽與正式接入

`NEXT_PUBLIC_SHOW_AD_PLACEHOLDERS=true` 顯示所有示意，改動後需重新建置。當前本機預覽已開啟；範例設定仍預設 false。關閉預覽不預留兩側或底部空白。

未載入 AdSense 腳本，未設定 publisher 或 slot ID，不產生廣告曝光或點擊。示意關閉按鈕只控制本站預覽。正式接入時移除示意浮層，由 Google Auto ads 的 Side rail（左右）、Anchor（底部）及 Vignette（插頁）管理實際廣告、關閉操作、觸發和頻率，不把手動廣告塞入自製彈窗。實際是否展示及尺寸由 Google 按裝置、空間、帳戶與投放條件決定。

待帳戶與站點設定齊備後再接入，處理適用私隱與同意安排及所需 ads.txt，並覆核閱讀空間。

官方參考：[Auto ads 格式及設定](https://support.google.com/adsense/answer/9305577?hl=en)、[Anchor ads](https://support.google.com/adsense/answer/15484692?hl=en)、[Side rail ads](https://support.google.com/adsense/answer/16531757?hl=en-GB)。
