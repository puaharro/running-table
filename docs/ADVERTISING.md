# AdSense 版位規劃

| 位置             | 桌面安排                                           | 窄畫面安排                                |
| ---------------- | -------------------------------------------------- | ----------------------------------------- |
| 總覽賽事列表右側 | 300 × 600 參考直幅位，畫面至少 1120px 時同列表並排 | 移到列表之後，調整為 300 × 250 參考方形位 |
| 獨立賽事資訊頁   | 官方資料卡下方側欄位，300 × 250 參考尺寸           | 跟隨側欄移到主要內容之後                  |
| 原創指南文章     | 目錄下方側欄位，300 × 250 參考尺寸                 | 跟隨側欄移到文章之後                      |
| 內容中段         | 保留原有 inline 位置                               | 隨正文寬度調整                            |

尺寸係版面參考，容器按可用寬度縮放。真實廣告接入時用相應 responsive 設定，唔以 CSS 裁切廣告。

## 預覽與接入

NEXT_PUBLIC_SHOW_AD_PLACEHOLDERS=true 會顯示廣告位預覽，改動後需重新建置。當前本機預覽已開啟；範例設定仍預設 false，避免未接入時留下空白側欄。

未載入 AdSense 腳本、未設定 publisher 或 slot ID，唔產生廣告曝光或點擊。待帳戶與站點設定齊備後再接入，處理適用私隱與同意安排及所需 ads.txt，覆核尺寸、閱讀空間及誤點風險。廣告同官方報名／篩選操作保持清楚區隔。

官方參考：[響應式廣告尺寸設定](https://support.google.com/adsense/answer/9183363/how-to-modify-your-responsive-ad-code?hl=en-GB)、[廣告格式 FAQ](https://support.google.com/adsense/answer/10734935?hl=en-GB)。
