# NXTGO 賽事體驗評級：編輯維護

目前準則：`2026-10-30-experience-v1`。這是人手編輯評論，不是由距離、時限或官方設施清單計出的演算法。舊版直觀資料比較已移出評級位置，原有官方賽事資料及核對日期保留。

## 評甚麼

- 賽道體驗：流動、超車、折返、路面、指示、景觀及節奏；賽道難度另作文字描述。
- 大會執行：領物、寄存、廁所、分流、工作人員、問題處理及離場。
- 補給體驗：位置、取用動線、供應及不同到站時段的經驗。
- 每項1–5整數；不足則null及原因，不設總分。準則及五級錨點在 `src/lib/rating-policy.ts`，公開方法頁與筆記頁共用。

## 原始資料與編輯判斷

`src/data/editorial-reviews.json`只存已整理及發布的評論，與官方catalog分開。每筆為一個賽事系列／組別及年份，不跨屆平均；`reviewTargets`明確對應目前列表組別，將來新增屆次要核對對應，不只按距離猜測。

必要欄位由 `src/lib/editorial-reviews.ts` 驗證：

- 年份、已發生的比賽日期、評論時間、評審、所用準則版本。
- 跑手位置、參賽／利益關係、觀察與記憶限制；未知可如實說明，不可補寫自費或全體共識。
- 每項分數、短評、優點／問題、適合對象，以及同屆材料id。
- 參賽／訪談紀錄、路線影片分析、官方背景各自標示；有分數必須有參賽或訪談材料。官方安排本身不能證明實際服務。
- 5分補給必須有連結的後段跑手觀察（材料的runnerSegment=back，或親身參賽者本身是後段）；多份筆記不等同多位獨立受訪者。
- 同一系列／組別／年份只維護一份編輯評論；如有多位跑手，整合證據、清楚分歧，勿假裝統計平均。

首輪港珠澳2025半馬分數3／4／3由編輯依使用者訪談作出：斜度較預期輕但景觀變化少、安檢接駁流程順暢但需預留時間、補給正常。明示單一前段跑手及記憶限制；沒有推論後段供應或等待分鐘。官方田總連結只確認2025-01-05日期，不支持體驗分數。

渣打全馬已知最近參賽年份2026，使用者自述共跑過8次；其餘年份及實際體驗未提供，不將8次當作8個樣本或填入分數。

## 由筆記到發布

1. 在 `/ratings/notebook/` 填寫一個年份的筆記，必要時新增另一屆。此頁只用瀏覽器localStorage；沒有伺服器儲存或登入後台。
2. 明確按「儲存此裝置草稿」，並下載JSON備份。匯入會新增草稿，不覆蓋目前內容；筆記可能包含未公開資料，不應放進公開資料檔。
3. 筆記的status=draft、format與正式評論不同，不能直接當成評論資料發布。編輯按實際材料整理短評，核對年份／組別／來源，讓參賽者檢視措辭及署名。
4. 將整理完成的評論填入editorial-reviews.json；參賽者的原始話語與編輯判斷分開，不補寫不存在的優點或問題。
5. 跑測試、正式建置、export及HTTP檢查，再檢查手機、往屆提示及組別隔離，循PR合併／部署。

規則修訂要更新版本與變更原因，重新審閱適用評論，不能把舊分數悄悄當成新規則的結果。本版尚未大規模校準，也未實作跑手公開投稿、雲端筆記、總分、排名或評分排序。
