## 已完成

- 32 項測試通過：原有篩選與日期邏輯，加上正式資料發布、來源引用、無佐證狀態、草稿／測試資料隔離、HTTPS 入口、負費用、精確截止、72 小時新鮮度、同組別起點、UTC 轉香港日期、收錄設定及 JSON-LD。
- TypeScript 檢查及 Next.js 生產建置通過。
- 匯出 16 個 HTML 頁面、366 個內部頁面／資產引用檢查通過；頁面有來源範圍說明、無測試活動混入、未載入廣告或分析腳本。
- HTTP smoke 檢查：13 個有效頁面路由回應 200，錯誤路由回應 404，靜態預覽拒絕 POST（405）。測試服務完成後自動停止。
- 正式 catalog 有 6 場活動、14 組；虛構資料只留喺 tests/fixtures。
- 程式已統一排版，備妥 GitHub Actions；未連遠端，唔聲稱遠端 CI 已執行。

## 尚未完成／驗證限制

- 瀏覽器工具先前受 URL 存取政策限制，未完成實際畫面、手機、鍵盤及 hydration 互動驗證；本批未用其他瀏覽器方式繞過限制。
- HTTP 狀態測試唔等於瀏覽器視覺或互動驗收。
- 聯絡資料按使用者決定稍後補齊；目前 SITE_INDEXABLE=false，未公開部署、未連 GitHub remote、未接入 AdSense。
- 當前工具清單未提供 Sites 發布工具，因此未建立託管項目或聲稱網站已發布。
- 正式 origin／收錄設定嘅建置分支未在真實網域環境驗證；已有純函數邏輯測試。
- 部分費用、起點及報名狀態仍待核對，按來源紀錄清楚留空；唔將已核實部分理解成資料完整。
- 無 JavaScript 時，報名狀態係建置快照。正式部署需配置更新及重新建置流程。

詳見 SOURCE_LEDGER.md、DEVELOPMENT.md 及 CHANGELOG.md。
