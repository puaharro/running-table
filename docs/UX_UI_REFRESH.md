# UX/UI 改版（2026-10-22）

## 設計方向

保留跑期品牌的珊瑚色，配深綠文字及淺綠背景；將首頁由大幅跑道宣傳區改為賽事導覽與下一場已收錄活動。導覽卡不聲稱報名開放，報名狀態仍由個別組別及核實時間判斷。

- 日期改為月曆標記；賽事名稱、距離、起點及報名狀態分層顯示。
- 桌面保留表格式對齊，手機以卡片顯示。
- 手機預設收起進階篩選；提供已選數目、移除條件、重設及「查看結果」返回結果區。
- 手機搜尋與日期輸入字體 16px，篩選主要操作保留至少 44px 高度。
- 使用同一組顏色與圓角調整詳情及指南頁。
- 保留 1440px 起左右外側廣告位、手機底部可關閉橫幅及手動開啟的全屏示意；未接入真實廣告。

## 驗證

- 生產建置及 TypeScript 通過。
- 匯出檢查：16 HTML 頁面，368 內部連結參照。
- 瀏覽器實測 390px、820px、1600px，檢查的總覽／詳情／指南頁沒有橫向溢出。
- 1600px 左右廣告位在中央正文之外，沒有重疊。
- 手機「5K + 九龍」組合篩選得到 1 場；「半馬 + 九龍」得到空結果，可移除或重設。
- 查看結果按鈕收起面板並返回結果區；手機廣告全屏開啟、關閉及底部橫幅關閉正常。
- 預覽已恢復瀏覽器原本尺寸及首頁。

## 維護

樣式放在 src/app/refresh.css，於 globals.css 之後載入；廣告容器的定位及斷點仍由 globals.css 管理。下一場活動卡依建置時日期選取；站點長期運行須隨資料更新重新建置。

## 三項 UX 改善（2026-10-22）

- 底部廣告以 sessionStorage 記住同一分頁本次瀏覽的關閉選擇；重新整理、進入詳情頁及返回均沿用。首次載入先讀取設定再顯示，避免已關閉的示意閃現；儲存被瀏覽器封鎖時仍可關閉當前示意。
- 新增「只睇可報名」切換：限定即將舉行及 open 狀態，保留搜尋、日期、距離、地區及排序；再按一次清除報名狀態篩選。狀態仍按同一個符合條件的組別判斷，不將候補或待核實當作開放。
- 卡片取符合篩選且可報名組別的最早截止時間，顯示完整剩餘日數；不足一日顯示小時，少於一小時顯示分鐘。原始截止時間及 HKT 標記保留。無截止資料、已截止、延期或核實過期的資料不顯示倒數；沿用每分鐘更新時鐘。
- 新增 7 項截止時間邊界測試，合共 39 項測試通過；TypeScript、生產建置及 16 HTML／368 內部參照匯出檢查通過。
- 瀏覽器驗證：只睇可報名得到 2 場；加「海濱」搜尋得到 1 場，網址同時保留 q 與 status；切換取消得到全部 6 場。手機 390px、桌面 1600px 無橫向溢出，桌面兩側廣告維持可見。關閉底部廣告後刷新及載入獨立賽事頁均維持隱藏，額外頁尾空間為 0。
