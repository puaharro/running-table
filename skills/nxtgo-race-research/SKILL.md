# NXTGO 賽事更新

先讀 repo 的 `AGENTS.md` 及[每輪更新流程](../../docs/CONTENT_OPERATIONS.md#每輪更新流程)。讀取私人工作區的上一輪摘要及待辦。除非營運者指定範圍，每輪按以下次序做四項：

1. **搵新賽事。** 查主辦方、田總及官方報名平台的香港路跑公告。按中英文賽名、屆次、日期及主辦方對照 `src/data/catalog.json` 及可見 CMS 建議。比賽組別、報名渠道和同一屆的不同寫法保留在同一賽事下。以官方當屆資料核對後，先進 CMS 待覆核清單。
2. **更新已收錄賽事。** 執行 `npm run review:data` 產生報名待覆核清單。優先查改期、取消、七日內截止與將開放的賽事。逐組逐渠道記錄官方來源、香港時間及欄位差異。申請、結果、付款期限分開記錄。未知名額保持待核實，查閱時間只更新實際核對的欄位。
3. **更新剛完賽一屆的跑手留言。** 先核對屆次及完賽狀態，再查看 CMS 現有草稿和材料。按[賽事研究 SOP](../../docs/RACE_RESEARCH_SOP.md) 逐類查原文並記錄覆蓋與限制。保留組別、來源及觀察範圍，去除同作者重複分享。以繁體中文整理賽道、補給、寄存、交通和大會安排。資料不足列缺口。待登入的平台沿用 SOP，並繼續查其他來源。
4. **更新首頁最新消息。** 用今輪已核實資料核對十四日內的報名截止和最近三十日核對的官方路線圖。按[首頁最新消息](../../docs/CONTENT_OPERATIONS.md#首頁最新消息)更新同一份賽事資料，核對中英文首頁顯示、消息退場和詳情連結。

將已確認的賽事資料接入網站賽事表，並按賽事 ID、屆次及組別接入已批准公開的當屆稿。網站稿須為每題提供正文、觀察限制和來源，資料不足就標明未知。公開頁沿用港珠澳半馬 2025 的[跑手分享版型](../nxtgo-site-qa/SKILL.md#跑手分享年份切換)。按[網站交付與驗收](../../docs/CONTENT_OPERATIONS.md#網站交付與驗收)核對表格、詳情頁、首頁消息和來源。需要頁面驗收時用 `nxtgo-site-qa`。

首次收錄賽事時記下香港日期，放在 `changes` 首筆。日後核對追加在後，讓賽事列表的 NEW 按首次收錄日期顯示 14 日。

在私人工作區保存本輪摘要，列出新增、資料變更、留言、首頁消息及待辦，附查閱範圍、頁面和目前進度。區分查無結果與未能查閱，並記下需要補查的日期。在已有匯入材料時，可按 [CMS 工作計劃](../../docs/CMS_JOBS.md) 產生待審建議。部署沿用現有授權流程。

## 報名資料自動覆核

先看 CMS「需要處理 → 報名資料自動覆核」，按[試行與覆核流程](../../docs/REGISTRATION_REVIEW.md)處理。共用官方網址只巡查一次，一般報名逐屆逐組核對入口、開放、截止、費用及名額。優先／精英另核資格、成績期、證明、適用的結果公布及付款期。慈善及旅遊只核對當屆官方或指定夥伴連結，共用連結集中處理。相同值自動保存核實紀錄。變更交營運者批准，讀取失敗或證據不足的欄位留待查。分開記錄最後嘗試及欄位核實時間。批准紀錄接入公開資料前重對現行值和依據。已獲官方證實全組額滿的賽事保留公告及核對時間，停止例行欄位覆核。個別組別有當屆官方額滿依據時，停止該組全部報名欄位的例行覆核，保留公告及核對時間。其餘組別繼續覆核。按賽事及官方來源集中處理待查。已核實開放的組別停止追查歷史開放時間。官方只列「額滿即止」時保存截止條件，仍核對名額。

查當屆表格的可選組別，再按各欄證據入庫。若組別未出現，記下限制並找官方公告。接入已批准資料後重新載入 CMS，核對剩餘待查及已批准項目。

## 研究待辦

按賽事及屆次查看下一步。待核實摘錄以同一原帖或影片集中覆核，保留逐則決定、理由及版本。續查記下原文連結、下一步及下次查閱日。待補材料草稿先補來源，更新後再回待審。操作跟隨[賽事研究 SOP](../../docs/RACE_RESEARCH_SOP.md#4-材料先保存後整理)及目前 checkout 提供的介面。
