# NXTGO 賽事研究

1. 讀取 repo 的 `AGENTS.md` 及 [賽事研究 SOP](../../docs/RACE_RESEARCH_SOP.md)。依營運者定下的賽事、年份、組別及交付範圍工作。查官方資料時，將報名截止、結果及繳費日期各自核對。
2. 研究跑手留言時，按 SOP 逐個來源類別檢查原文，記錄查閱時間、來源及限制。搜尋摘要只作線索。遇登入或驗證，保留待處理狀態並繼續其他來源。匯入私人 CMS 時保留材料 ID 及屆次／組別依據。
3. 用繁體中文整理觀察，清楚交代組別、適用範圍、資料不足和不同經歷。引用已匯入材料，保留出處，避免由個別經歷推斷整場表現。
4. 依 [CMS 工作計劃](../../docs/CMS_JOBS.md) 將指定材料及正文交到 CMS 覆核。對照 proposal ID、引用編號和未完成來源。需要檢查公開頁時用 `nxtgo-site-qa`。
5. 由營運者確認稿件、評分及批准發布。研究、稿件及工作計劃保存在私人工作區。
