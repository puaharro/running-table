# NXTGO 網站驗收

使用現有網站與已確認資料，不另建 CMS 或評分系統。預設只查／本機修正；驗收通過不代表稿件確認、commit、push 或發布批准。使用者已有明確指定版本與授權時按範圍執行，不重複索取同範圍批准。

## 開始與基準

在目前 checkout 讀 `AGENTS.md`、`docs/SITE_QA_SOP.md` 及 `package.json`。已知 repo 為 `/Users/paul/Documents/ChatGPT/比賽時間表website`；位置改變時先定位，不另起替代網站。沿用 SOP 作詳細程序與紀錄格式，指令以現行 repo 為準。

固定本輪 commit、未提交修改、目標頁及授權上限，不自行用最新 main 代替指定版本。恢復已有稿件 ID／屆次／組別／版本、評分與可查的人工確認狀態；未知就記未知，不代產批准收據。正式部署與本機可能不同版本，要分開標示。

## 最小而有證據的驗收

- 重用現有預覽，依終端回傳網址操作。先以 390×844 完整測試，320×568 查窄屏，844×390 查轉向及篩選遮罩；有具體問題才補其他尺寸。使用可用的受支援瀏覽器控制工具，完成後恢復臨時 viewport。
- 檢查搜尋、無結果／清空、日期／地點／距離組合、套用／重置、報名狀態、三種排序，以及適用的重新載入／返回／分頁。依當時資料推導預期結果，不把歷史場數當固定答案。
- 等載入提示消失及目標狀態可見後才評估。日期直接填值沒有觸發應用更新時，用原生鍵盤分段輸入或日期選擇器重試；不把測試工具限制當缺陷，也不用頁面 JS 模擬互動來宣稱通過。
- 用 `npm run check:content -- --base-url <本機 origin>` 核對實際 HTTP 內容，或用 `--directory <本輪靜態輸出>`。目前只覆蓋兩場已選定的 2025 稿，完整 export 檢查另含 RMAC、私檔排除及頁面隔離；不能宣稱核對了所有賽事。舊 out 通過不等於本輪版本通過。
- gated Sites 的 HTTP 登入／401／轉址不是正文驗證成功；改用已登入瀏覽器核對相同項目，必要登入請擁有人協作。不改存取設定、不要求或把憑證寫入指令／紀錄。

## 修正與交付

只在有可重現問題時改碼，保存尺寸、步驟、期望／實際及私人截圖。先核對上游讀取限制，資料未知不自動補成事實。完整評語、逐項分數／未評、五主題全文、來源、未知與觀察限制保持原已確認版本；變更評論需要擁有人對完整修訂稿重新確認，不能改基準 hash 讓測試過關。

按改動範圍跑測試與重測；純檢查不重建相同版本，正式輸出有改動才補建置／export／HTTP。正式建置與正在運行的 dev 預覽分開 checkout，避免共用 `.next`。只有獲授權發布才讀 `docs/DEPLOYMENT.md` 並使用現有部署工具，保留確切來源／部署版本對應；不從 QA 任務推定部署權限。

結果保存於 `.editorial-private/site-qa/` 或私人 CMS；原文、待覆核材料、截圖、登入資料不提交。只報告實際完成的測項、失敗／未測／工具限制、修正及回歸、內容保持情況、本機網址和實際部署狀態。尺寸模擬不能稱實體手機已測。
